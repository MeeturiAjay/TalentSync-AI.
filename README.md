# TalentSync AI 🚀🤖

**TalentSync AI** is a powerful, intelligent, and fully-automated multi-agent platform for job screening. It leverages state-of-the-art AI agents to summarize job descriptions, extract candidate data from resumes, evaluate eligibility, and automate personalized email responses — all in seconds.

---

## 🌟 Key Features

- 🔍 **Automated Job Screening**: Uses powerful LLM agents to understand job descriptions and assess resumes accordingly.
- 🧠 **AI-Powered Evaluation**: Natural language understanding of candidate profiles for accurate matching.
- 📄 **Resume Parsing & Entity Extraction**: Smart parsing to extract key information like name, email, skills.
- 📬 **Email Automation**: Sends customized emails to selected candidates based on evaluation.
- 🧭 **Agent-Based Workflow**: Modular LangChain agents handle summary, eligibility, and email dispatching.
- ⚡ **Fast & Efficient**: Accelerated using Groq for real-time inference and FAISS for semantic search.

## 🧪 How It Works

1. **Upload** the job description and candidate resumes.
2. **LangChain agents**:
   - 🔍 Summarize JD
   - 📄 Extract candidate name/email from resume
   - ✅ Evaluate eligibility
3. **Result**: Clear eligibility output with email-ready summaries.
4. 📬 **Email Agent** auto-sends emails to selected candidates.
